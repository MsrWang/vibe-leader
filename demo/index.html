预期的 Codex 处理

合成示例，非实测记录

1. 核对当前项目

先完整读取绑定说明，再独立执行 pwd，核对项目目录、身份和当前规则。无法确认身份时停止。

2. 给出最小计划

目标：添加待办、勾选完成、刷新后保留。非目标：账号、云端同步、公开部署。列出拟修改文件及检查方法。

3. 连续推进到检查点

当前只完成调查与计划，没有修改项目。确认具体文件范围和本地验证影响后，在条件保持稳定时连续完成这一批相关本地步骤，直到形成可检查的阶段结果或遇到明确停止条件。

需要你确认的下一步

确认最小计划与本地修改范围；此页面的操作不会替你批准项目任务。

把 Skill 装到 Codex，再到项目里调用

  1. 获取完整源码

    从 GitHub 的 Releases 下载完整源码包，保留许可和第三方通知。使用其中的安装指南核对实际宿主与安装目录。

  2. 安装或受控升级

    3.0.3 增加可选的本地证据筛选；使用 3.0.2 或更早版本时，需要按入门指南更新实际安装。本版安装器使用已确认的 CODEX_HOME/skills；文件核验通过后，还要在 Skills 中确认“中文跨项目研发主管”可见且启用。

  3. 显式调用

    在实际项目任务中选择该 Skill，或在请求中写出下面的技术标识；随后说明目标和本次范围。

    使用 $vibe-project-lead-zh。先绑定当前项目，只读调查后告诉我目标、风险和最小下一步，暂不修改。

Skill 与源码工具的区别

安装的 Skill 是 13 个文件，包含可选的本地证据筛选脚本。筛选器和完整源码中的 Python 安装器、workbench 工具都需要显式使用，不会自动注入每次 Codex 对话；本静态页面也不会运行它们。

版本与使用边界

支持范围
对应 Vibe Leader 3.1.0 候选。macOS 14+、Apple Silicon M1+ 和稳定版 Python 3.11+ 是设计目标；CPython 3.14.7 与 2026 Mac mini（M6）是参考验收目标。真实 Mac 技术检查与 Codex App 用户观察尚未完成；3.0.3 继续作为稳定版。
示例性质
这些文字用于理解流程；不是实际会话回放、在线模型、性能评测或用户验收记录。复制提示词后，需要在自己的 Codex 中按真实目标调整并使用。
权限边界
Skill 是工作指令，不是 OS 沙箱。模型可能偏离流程；实际工具权限、目录与操作影响仍须核对。测试通过不能代替真实用户接受。
数据去向
本页不接模型、不收代码或 Token、不自建追踪、不保存会话；复制按钮仅写入选定的合成文本，不读取剪贴板。托管平台有自身政策；实际 Codex 可能把上下文发送给配置的模型服务。
