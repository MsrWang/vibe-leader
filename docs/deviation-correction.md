# 感觉项目跑偏时，直接这样说

你不需要先判断是需求、代码、计划还是 Skill 出了问题。只要在当前项目任务里告诉主管：

```text
使用 $vibe-project-lead-zh。我感觉当前推进有偏差，但我说不清技术原因。
请根据整体目标、最新决定和当前行动帮我判断，给出最小修正；
如果仍在已有授权范围内，说明后直接继续，不需要我再说一次“继续”。
```

## 默认只显示三行

```text
纠偏判断：当前是否偏离，以及属于哪一类。
最小修正：停止、保留和恢复什么。
现在继续：现有授权内立即执行的下一项。
```

只有目标冲突、证据不足、需要你决定，或者你要求详细解释时，才展开整体目标、当前检查点、实际行动、偏差类型、判断依据和最小修正。

主管应区分执行没有落实、范围扩大、局部工作占据主线、用户真正改变目标、暂无偏差证据和证据不足。必要的中间步骤不因为暂时没有最终结果就算跑偏。

已经有效完成的成果继续保留，只重新打开受影响的步骤。同一偏差没有新证据时不重复展示完整纠偏卡。纠偏不会产生新的授权；涉及新项目、新目标、账号、网络、安装、发布或其他外部动作时，仍需在具体动作前单独处理。
