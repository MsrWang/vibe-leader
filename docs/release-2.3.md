- 加密的派发日志无法独立逐字核对原始明文，因此不宣称已完成该项来源验证。

- 旧 Git、已有子模块内容、可选 SHA-256 写入委派和 Windows-native 等仍有限制；详见[限制说明](limitations.md)。
